## Projeto em destaque

### Sistema de Gestão Operacional Logística

Plataforma web criada a partir de necessidades reais de operações logísticas e centros de distribuição. O projeto centraliza dados, indicadores, registros e tratativas em uma experiência única e rastreável.

| Área | Soluções desenvolvidas |
| :--- | :--- |
| **Gestão operacional** | Dashboards, indicadores e acompanhamento de resultados |
| **Armazém e expedição** | Controles operacionais, PA–Cross, pallets e processos de DRP |
| **Dados** | PostgreSQL, importação de Excel, tratamento e exportação de informações |
| **Aplicação** | Autenticação, perfis de acesso, CRUDs e APIs REST |
| **Automação** | Calculadora de recebimento e redução de tarefas manuais |

**Stack principal:** Python, Flask, JavaScript, HTML5, CSS3, PostgreSQL, Excel e APIs REST.
